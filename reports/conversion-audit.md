## 1. 商业转化漏斗全链路设计

本站摒弃了普通采集站通篇挂满弹窗广告的恶劣体验，构建了**以技术信任为基石、以客观评测为桥梁、以透明披露为前提**的健康转化漏斗：

```
技术长尾搜索 (解决具体痛点: 如 GitHub 超时 / 奈飞无法点亮)
      ↓
技术教程与排障文章 (建立专业信任，指出需要高品质专线支持)
      ↓
品牌独立深度评测 (/reviews/{slug}/) / 横向对比 (/compare/{a}-vs-{b}/)
      ↓
客观参数考量 (明示适合谁、绝不推荐谁，还原真实年付折算价格)
      ↓
合规披露商业卡片 (明确展示优惠券码、合作关系提示与外部注册链接)
      ↓
用户自愿理性注册转化
```

## 2. 核心商业组件与合规规则审查

### 1. `ComplianceAffiliateBox` 组件规范
- **商业关系明示**：所有合作推荐位必须带有显著标签：“客观百科中立原则：如实披露品牌商业关系，不冒充官方或独立测评”。
- **推广链接属性检查**：
  ```html
  <a href="..." target="_blank" rel="nofollow sponsored noopener">
  ```
  全站 100% 商业链接均包含 `rel="nofollow sponsored noopener"` 属性，严防外链权重惩罚。

### 2. 优惠码与折扣信息核对
- **光速云**：专属新人优惠码 `AMM`，折算年付起步价约 ¥8.25/月；
- **真实价格透明化**：在卡片中清晰提醒用户“年付 99 元平均折算成本，不可按单月 8 元购买”，防止产生价格误导引发退款纠纷。

### 3. CTA 与使用场景匹配度
- 纯技术教程页（如 UWP 回环隔离修复）不强行插入购买弹窗，仅在相关章节提及“若为机场链路问题可参考对应品牌专线评测”；
- 导购型文章（如“买月付还是年付”、“双持备用机场”）重点展示不同计费模式的优劣，引导用户优先购买月付进行真实晚高峰验证。
